
# Project 8: Multilingual To‑Do List Manager

## Objective  
Design a to‑do list manager that supports multiple languages using your i18n workflow. Tasks can be added, marked complete, and displayed in different locales.

---

## Attributes  
- **`_tasks`** → list storing task objects.  
- **`_locale`** → current language setting for display.  
- **`_completed`** → list of completed tasks.  

---

## Methods  
- **`add_task(description)`** → add a new task.  
- **`complete_task(task_id)`** → mark a task as complete.  
- **`list_tasks()`** → return all tasks in the current locale.
